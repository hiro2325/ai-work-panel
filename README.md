# AI作業パネル（個人情報マスキングツール）

ケアマネジャー（介護支援専門員）が、ケアプランやモニタリングなどの書類を AI に手伝ってもらうためのツールです。
**書類を AI に渡す前に、利用者・家族の名前や住所などの個人情報を【利用者001】のような記号に置き換えます。AI の作業が終わったら、同じツールで元の名前に戻します。**
処理はすべてパソコンの中で行い、インターネットには一切つなぎません。

> **このリポジトリに出てくる人名・事業所名・住所・フォルダの場所は、すべて架空のものです。**
> （例：さくら居宅介護支援事業所、見本 太郎、架空県虹彩市星降町、`\\server\share\利用者` など）

---

## 1. 概要：何を解決するツールか

### 困っていたこと
- 介護の書類（アセスメント・ケアプラン・支援経過・モニタリング）は量が多く、AI に下書きや転記を手伝ってもらうと大きく楽になる。
- しかし書類には、利用者・家族の氏名、生年月日、住所、電話番号、被保険者番号などが書かれていて、そのまま AI に渡すことはできない。
- 手で黒塗りや書き換えをすると時間がかかり、見落としも出る。AI が書いたあとに名前を手で書き戻すのも手間で、間違いのもとになる。

### このツールがすること
```
 本物の書類（Excel・Word・PDF）
   │ ① 資料を入れる
   ▼
 ② 個人情報を記号に置き換える  ……  見本 太郎 → 【利用者001】
   │    迷う所は橙色で止め、人が確かめる      架空県虹彩市星降町1-2-3 → 【住所001】
   ▼
 ③ AI に渡す（記号だけの書類が AI 作業フォルダへ）
   │
   │   …… AI が記号のまま書類を作る ……
   ▼
 ④ 届いた書類を元の名前に戻す  ……  【利用者001】 → 見本 太郎
   ▼
 ⑥ 完成した書類
```
- 氏名と記号の対応表（記号対応表）は、AI から見えないフォルダにだけ置きます。
- 同じ人はいつも同じ記号になるので、AI は記号のままで書類の中身を理解して作業できます。
- Excel・Word は書式を保ったまま置き換え・書き戻しをします。ヘッダー・フッター、計算式が参照するセルも対象です。
- FAX やスキャンの PDF は、Windows に入っている文字読み取り機能（オフライン）で文字にしてから置き換えます。

## 2. 使い方

### 2-1. 用意するもの
- Windows 10 / 11
- Go 1.24 以上
- 結果の書類を開くための Excel・Word（なくても LibreOffice で開けます）

### 2-2. Go の入れ方
1. <https://go.dev/dl/> から Windows 用のインストーラー（`go1.xx.x.windows-amd64.msi`）を入手して実行します。
   コマンドで入れる場合：`winget install GoLang.Go`
2. 新しく開いたコマンドプロンプトで、次のように表示されれば準備完了です。
   ```
   > go version
   go version go1.24.x windows/amd64
   ```
   外部のライブラリは使っていません（Go の標準ライブラリだけ）。`go mod download` などの準備は要りません。

### 2-3. 起動のしかた
1. このリポジトリを取得します。
   ```
   git clone <このリポジトリのURL> kadai_panel
   ```
2. `kadai_panel\run_source.bat` をダブルクリックします。
3. 黒い画面が開き、少し待つとブラウザに「AI作業パネル　さくら居宅介護支援事業所」が開きます。
   - 黒い画面は、使い終わるまで閉じないでください（閉じるとパネルも止まります）。

`run_source.bat` は、ツールが使うフォルダを、このリポジトリの中の練習用フォルダに向けてから起動します。

| 設定 | 向け先 | 中身 |
|---|---|---|
| `MASKTOOL_WORK_DIR` | `kadai_masking\` | 本物の名前が入る作業フォルダ（元データ・完成品・氏名一覧・記号対応表） |
| `MASKTOOL_AI_DIR` | `kadai_ai\` | AI が読み書きするフォルダ（記号だけの書類） |
| `MASKTOOL_SERVER_BASE` / `_ENDED` | `kadai_server\riyousha` / `riyousha_end` | 事務所サーバーの利用者フォルダの代わり |

> exe を直接開かず、必ず `run_source.bat` から起動してください。設定がないと、ふだんのパソコンの作業フォルダを見に行ってしまいます。

### 2-4. 画面の流れ
パネルのトップに、仕事の順に6つの枠が並んでいます。

| 枠 | すること |
|---|---|
| ① 資料を入れる | Excel・Word・PDF をドラッグして入れます。録音の文字起こしは、貼り付けると Word にして入ります。はじめての利用者・家族は、ここで氏名を登録します。 |
| ② 置き換えて確認する | 「名前などの個人情報を記号に置き換える」を押します。**緑**＝記号にした所、**橙**＝人が確かめる所。橙の語は「利用者／家族／その他／除外／住所」のボタンで仕分けて、もう一度置き換えます。 |
| ③ AI に渡す | 利用者・書類の種類・月を選んで「OK・AI に渡す」を押します。記号だけの書類が `kadai_ai\30_記入係作業中\` に入り、`kadai_ai\00_指示\` に依頼の書き置きができます。橙が残っている間は押せません。 |
| ④ 届いた合格品 | AI が `kadai_ai\40_合格・確認待ち\` に置いた書類が出ます。「記号を名前などの元の個人情報に戻す」で元の名前に戻します。 |
| ⑤ 要相談 | AI が止まった仕事と、その理由が出ます。 |
| ⑥ 完成した書類 | 元に戻した書類（`kadai_masking\2_完成\`）を開く・ダウンロードフォルダへ写す・サーバーへ保存する・片づける、ができます。 |

そのほかに、氏名一覧の画面での編集、支援経過（1日分）の書き足し、サーバーの名前をそろえる、などの画面があります。
詳しくはパネルの「使い方」（[src/w27/使い方.html](src/w27/使い方.html)）をご覧ください。

## 3. 動作確認の手順（samples の架空の書類で試す）

`samples\` に入っている2つの試し用書類で、置き換え → 確認 → AI に渡す → 元に戻す、までを試します。
できるファイルは `kadai_*` フォルダに入り、Git には上がりません。**本物の書類は使わないでください。**

### 試し用の書類（samples）
| ファイル | 中身 |
|---|---|
| `サンプル_フェイスシート.xlsx` | 利用者の基本情報（氏名・フリガナ・生年月日・住所・電話・被保険者番号・家族構成・緊急連絡先など） |
| `サンプル_支援経過記録.docx` | 3日分の支援経過（訪問・電話・事業所との連絡） |

出てくる人物・住所・番号は、すべて架空です。

| 書類での役 | 名前など |
|---|---|
| 利用者 | 見本 太郎（ミホン タロウ）、昭和15年3月2日生 |
| 妻（同居） | 見本 花子 |
| 長男（別居） | 見本 一郎 |
| 住所 | 〒999-9999 架空県虹彩市星降町1-2-3 星降ハイツ101号 |
| 電話・被保険者番号 | 000- で始まる番号、0000012345 |
| よその事業所の職員 | 例田さん（ほしぞら訪問介護） |
| 自分の事業所の担当ケアマネ | 手本 由紀 |

### 手順1　起動する
`run_source.bat` をダブルクリックし、ブラウザにパネルが開くことを確かめます。

### 手順2　利用者と家族を登録する
トップの下の「氏名一覧を開く」→「＋ 新しく追加する」で、次の3人を登録します（姓と名の間にスペースを入れます）。

| 区分 | 氏名 | 呼び名 |
|---|---|---|
| 利用者 | 見本 太郎 | ミホン タロウ |
| 家族 | 見本 花子 | |
| 家族 | 見本 一郎 | |

ここでは、わざと **例田さん・手本 由紀・住所は登録しません**。手順4で、ツールが止めて確認を求めることを確かめるためです。

### 手順3　書類を入れる
`samples\` の2つのファイルを、①「資料を入れる」の枠にドラッグします。
（ファイルは `kadai_masking\1_元データ\` に写ります。`samples\` の元のファイルはそのままです）

### 手順4　置き換えて、橙を確かめる
②「名前などの個人情報を記号に置き換える」を押します。2つとも橙が出て、AI には渡せない状態で止まります。

| ファイル | 橙で止まる語 | 押すボタン |
|---|---|---|
| フェイスシート | `架空県虹彩市星降町1-2-3 星降ハイツ101号`（番地まである住所） | 住所として置き換える |
| フェイスシート・支援経過 | `手本 由紀`（敬称のない名前らしき語） | 除外（自分の事業所の職員なので、AI に渡してよい） |
| 支援経過 | `例田さん`（氏名一覧にない「〇〇さん」） | その他（よその事業所の職員） |

- 橙が残っている間は、③ で AI に渡せないことも確かめます。
- 3つとも仕分けたら「もう一度置き換える」を押します。橙が消え、緑（記号にした所）だけになります。

### 手順5　置き換えの結果を確かめる
② の画面で、次のように記号になっていることを確かめます（かっこ内の元の名前は、この画面にだけ表示されます）。

| 元の文字 | 記号 |
|---|---|
| 見本 太郎 ／ ミホン タロウ | 【利用者001】／【利用者001の呼び名1】 |
| 見本 花子 ／「花子さん」 | 【家族001】／【家族001の名】さん |
| 見本 一郎 ／「一郎さん」 | 【家族002】／【家族002の名】さん |
| 〒999-9999 架空県虹彩市星降町1-2-3 星降ハイツ101号 | 【住所001】（郵便番号から部屋番号まで1つ） |
| 昭和15年3月2日 | 【古い日付001】 |
| 000-0000-0000、000-1111-2222 | 【電話001】、【電話002】 |
| 0000012345 | 【番号001】 |
| 例田 | 【その他001】 |

`要介護2`・`星降クリニック`・`手本 由紀`（除外）など、個人情報ではない語はそのまま残ります。
（記号の番号は、はじめて試したときのものです。前に試したことがあると、番号が変わることがあります）

### 手順6　AI に渡す
③ で利用者（利用者001）・書類・月を選んで「OK・AI に渡す」を押します。次の2つができていることを確かめます。
- `kadai_ai\30_記入係作業中\（仕事の名前）\資料\` に、記号だけの2つの書類
- `kadai_ai\00_指示\` に、依頼の書き置き（.md）

書類を開いて、**見本・例田・虹彩市・000- の番号が1つも入っていない**ことを目で確かめます。

### 手順7　AI の作業の代わりをする
本来は AI が書類を作って 40 に置きます。ここでは手で代わりをします。
1. `kadai_ai\40_合格・確認待ち\` の中に、手順6の「仕事の名前」と同じ名前のフォルダを作ります。
2. 手順6の2つの書類を、そこへコピーします。
3. （任意）コピーした `サンプル_支援経過記録.docx` を Word で開き、最後に次の1文を書き足して保存します。AI が書いた文の記号も戻ることを確かめられます。
   ```
   【利用者001】様の夜間の排泄について、【家族001】さんの負担を減らす方法を次回の担当者会議で検討する。
   ```

### 手順8　元に戻す
パネルの ④「届いた合格品」に、その仕事が出ます（10秒ごとに自動で確かめます）。
「記号を名前などの元の個人情報に戻す」を押し、⑥「完成した書類」から開いて、次のことを確かめます。
- 名前・住所・生年月日・電話・被保険者番号が、元の文字に戻っている
  （フルネームは、姓と名の間のスペースがなくなって `見本太郎` の形で戻ります。これはツールの決まった動きです）
- 手順7で書き足した文が `見本太郎様の夜間の排泄について、見本花子さんの…` に戻っている
- 完成品は `kadai_masking\2_完成\` に入っている

### 手順9　（任意）片づける
⑥ の「片づける」を押すと、確認の画面のあとで、この仕事で使ったファイルが Windows のごみ箱へ移ります（ごみ箱から戻せます）。

### もう一度はじめから試すとき
`kadai_masking\` の中の `対応表\`（氏名一覧・記号対応表）などを消すと、はじめての状態に戻ります（`.gitkeep` は残してください）。

## 4. 設計上の判断

ソースから読み取れる工夫と、その理由です。

### 4-1. パソコンの外に出さない
- パネルは `127.0.0.1` の空いているポートでだけ待ち受けます（[panel.go](src/w27/panel.go)）。同じネットワークのほかのパソコンからは開けません。
- 起動のたびに作るランダムな合言葉（トークン）を URL に付けます。書き込みの操作は、そのトークンと Host の一致を確かめてから受け付けます。ほかのサイトのページから、パネルを勝手に操作されないようにするためです。
- PDF の文字読み取りは、Windows に最初から入っている `Windows.Media.Ocr` を使います（[pdf.go](src/w27/pdf.go)）。外部の OCR サービスには送りません。
- 外部ライブラリを使わず、Go の標準ライブラリだけで書いています。画面の HTML・様式ファイルは `go:embed` で1つの実行ファイルに入れます。配る物を1つにでき、知らないコードが入る心配も減らせます。

### 4-2. 本物の名前と AI の置き場所を分ける
- 本物の名前が入る「作業フォルダ」と、AI が見る「AI 作業フォルダ」を別にしています。作業フォルダが AI 作業フォルダの中にあると、起動の時点で止まります（[main.go](src/w27/main.go) `setupPaths`）。
- 支援経過など本物の名前を書くファイルも、書く前に場所を確かめ、AI 作業フォルダの中なら書きません（[keika.go](src/w27/keika.go) `keikaGuard`）。
- エラーの記録は AI 側に残しますが、ファイル名・実名・住所・電話は書かず、「ファイル1（.xlsx）」「【利用者017】」のように書きます（[errlog.go](src/w27/errlog.go)）。

### 4-3. 黒塗りではなく「記号」に置き換える
- 名前を消すと、AI は「だれが・だれに・何をしたか」が分からなくなります。【利用者001】【家族001】のような記号なら、続柄や人の区別が保たれ、AI は文の意味を理解したまま作業できます。
- 記号と元の名前の対応は `記号対応表.tsv` に残します。同じ人はどの書類でも同じ記号です。氏名を直しても前の記号は消さないので、前に渡した書類も元に戻せます（[store.go](src/w27/store.go)）。
- 住所は人に結び付けず【住所001】として1つのかたまりにします。郵便番号から建物名・部屋番号まで、セル内の改行やヘッダーをまたいでも1つとして扱います（[addr.go](src/w27/addr.go)）。

### 4-4. 迷う所は止めて、色で人に確認させる
- 自動で決めきれない語（氏名一覧にない「〇〇様」、番地まである住所、8けた以上の数字、読み取りで化けた名前、伏せ字 など）は、置き換えずに**保留**にし、AI には渡しません。見落としより、止めすぎのほうが安全だからです。
- 画面では**緑＝記号にした所、橙＝確かめてほしい所**と色で分け、橙の語はボタン1つで「利用者／家族／除外／住所」に仕分けられます。
- 「看護師」「大和」のようによく出る語も、名字と同じ字のことがあるので、自動では除外しません。1つの箱にまとめて、人が1回押せば済むようにしています（[commonwords.go](src/w27/commonwords.go)）。
- 「AI に渡す」ときにも、選んだ利用者が出てこないファイル（別の方の書類が混ざっている）や、AI へのひとことに名前らしき語があれば止めます（[panel.go](src/w27/panel.go)）。

### 4-5. 書式を壊さずに、元どおりに戻す
- Excel・Word（OOXML）は、ライブラリで開いて保存し直すのではなく、中の XML の文字の部分だけを書き換えます（[ooxml.go](src/w27/ooxml.go)・[xmlscan.go](src/w27/xmlscan.go)）。罫線・印刷設定・計算式・ヘッダーの書式記号には触れないので、元に戻すと見た目まで元どおりになります。
- 様式の「個人情報が入るセル」は `登録セル.txt` に登録しておき、中身が何であっても必ず記号にします。そのセルを参照する計算式（年齢・西暦など）も対象にし、元に戻すときは数値や日付の形で書き戻します（[cells.go](src/w27/cells.go)）。

### 4-6. 消さない・上書きしない・押すまで何もしない
- 片づけはファイルを消さず、Windows のごみ箱へ移します（[trash_windows.go](src/w27/trash_windows.go)。cgo なしで `SHFileOperationW` を呼ぶ）。ごみ箱から戻せます。
- 片づけ・書き足し・サーバーへ保存・名前をそろえる、はどれも、まず「何をどうするか」の確認画面を出し、押したときだけ動きます。確認のあとで中身が変わっていたら、動かずに止まります。
- サーバーには上書きしません。同じ名前があれば別の名前で保存し、書き足す前には「控え」に写しを取ります（[serversave.go](src/w27/serversave.go)）。
- 依頼の書き置きなどは、一時ファイル（`.part`）に書いてから名前を変える形にし、途中で止まっても書きかけのファイルが残らないようにしています（[panel.go](src/w27/panel.go) `copyBytes`）。

## 6. フォルダの構成

```
kadai_panel/
├─ run_source.bat        起動用（練習用フォルダに向けて go run する）
├─ samples/              動作確認用の架空の書類（Excel 1つ・Word 1つ）
├─ src/w27/              ソース（Go・パネルの HTML・様式のひな形）
│   ├─ main.go             起動・フォルダの準備・置き換え／元に戻すの本体
│   ├─ panel.go / panel.html  ブラウザの画面
│   ├─ rules*.go / addr*.go   名前・住所などの見つけ方
│   ├─ ooxml.go / xmlscan.go  Excel・Word の中身の読み書き
│   ├─ pdf.go              PDF の文字読み取り
│   └─ 使い方.html          利用者向けの説明書
├─ kadai_masking/        作業フォルダ（本物の名前が入る。Git には上げない）
├─ kadai_ai/             AI 作業フォルダ（記号だけ。Git には上げない）
└─ kadai_server/         事務所サーバーの代わり（Git には上げない）
```

## 7. 掲載データについて

このリポジトリに出てくる人名・事業所名・住所・電話番号・フォルダの場所は、**すべて架空のもの**です。実在の人物・団体とは関係ありません。
試すときも、架空の人物・架空の書類だけを使ってください。
